# 13 — Anti-flat / non-repetitive playbook

## Diagnose why a visually advanced stack still produces flat results
- Overprescriptive existing design system templates that default to card grids.
- Agent optimizes for compile/build speed instead of experiential outcome.
- Design brief lacks a hero silhouette and explicit spatial design concept.
- 3D terminology interpreted as CSS tilt, not volume/camera interaction.
- Every use case mapped to the same orbit/radial node visualization.
- Lack of evaluation screenshots or side-by-side alternatives.
- Overweighting accessibility as a pretext for bland design; accessibility is a design constraint, not an aesthetic ban.

## Required interventions
1. Before coding, document a first-frame composition and an interaction storyboard with at least three meaningful frames.
2. Build **two different prototypes** for any flagship task before final selection (unless user specifically chooses one after comparing designs). One should challenge current site's composition.
3. Use a visual-repetition ledger: route, dominant layout, 3D/2.5D style, material family, navigation pattern, interaction signature; prevent consecutive reuse.
4. Provide actual browser screenshots and behavior evidence. Textual claims of richness insufficient.
5. Ban the default rescue: replace flat cards with hover scale + gradient + generic particles. Require redesign of information topology/staging, not cosmetics.
6. Give one composition priority; secondary effects stay subordinate.

## Richness dimensions (not additive clutter)
- Composition: silhouette, hierarchy, asymmetry, negative space, pacing.
- Space: camera, scales, overlapping planes, foreground/background narrative.
- Material: surface response, silhouette lighting, reflections constrained by budget.
- Interaction: direct manipulation, causal feedback, visible reversibility.
- Motion: entrance, focus, morph, settle, semantic transitions.
- Information: contextual layers, provenance, relations, progressive disclosure.
- Emotion: distinct visual voice with restraint in effect density.

## Variety ledger example
Landing: kinetic editorial + layered 2.5D typography; Atlas: organic spatial graph; DP-600 OneLake: architectural cutaway; SQL Window Functions: execution microscope; Portfolio: project diorama; Statistics: precise 2D plots plus 3D educational mechanism only when useful. Different tasks invite different material language; don't impose one palette or layout.

## Critique vocabulary
Avoid 'looks nice'. Ask for specific corrections: 'hero silhouette indistinct', 'depth cues inconsistent', 'focus object not dominant', 'camera motion distracts from learning', 'edge labels occluded', 'interaction payoff weak', 'mobile acts as shrunk desktop', 'asset style inconsistent', 'identical scene grammar to adjacent route'.
