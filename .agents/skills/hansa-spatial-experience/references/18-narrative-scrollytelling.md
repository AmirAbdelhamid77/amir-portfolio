# 18 — Spatial storytelling and scrollytelling

## Narratives with agency
Scene-driven storytelling should be user-paced, skippable, searchable and interruptible. A timeline or scroll can control a scene without hijacking all page scrolling. Never hide initial content behind a forced introduction.

## Story arc grammar
Setting / observed fact → tension/question → mechanism → supporting evidence → interpretation → next learning action. Align camera framing and typographic rhythm to these beats; each transition has one message. Provide source citations/links alongside results.

## Spatial camera stage plan
- Opening: establish architecture of problem and primary question.
- Detail push-in: focus component relevant to current evidence.
- Cutaway: show internals with labeled textual explanation.
- Comparison: synchronize viewports and scale to compare fairly.
- Reflection/recap: return to overview with persistent landmarks.
- Next action: links/quiz/related concepts visible and focusable.

## Timing and control
Scroll scrub and manual step buttons should drive same state machine. Scenes can settle immediately in reduced-motion mode. Scene markers/bookmarks must represent actual narrative stages, not arbitrary scroll percentages with hidden meaning.

## Application ideas
Daily Insight Timeline with provenance; DP-600 data lifecycle guided museum; SQL query explanation; portfolio case study with verifiable impact; data storytelling course analytical argument tour; history of learning milestones when actual dates exist.
