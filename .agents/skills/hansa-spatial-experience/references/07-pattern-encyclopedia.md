# 07 — Visual pattern encyclopedia: avoid narrow stylistic vocabulary

**Selection rule:** choose patterns for user task and real data, and mix at most two major metaphors per scene. The presence of a pattern here is NOT instruction to use it indiscriminately. Use `assets/pattern-registry.json` for machine-readable taxonomy.

## A — Spatial navigation and information architecture
1. Living Constellation — focus-preserving concept constellation with semantic links.
2. Knowledge Atrium — walkable 3D gallery with semantic rooms and DOM index.
3. Orbital Library — concentric rings by genuine category (not invented importance).
4. Exploded Navigation Shell — sections detach around central concept.
5. Relational Terrarium — organic clusters grounded in graph edges.
6. Layered Index Wall — 2.5D wall of content facets and searchable headings.
7. Deep Focus Stage — selected entity grows into central stage, nearby links retained.
8. Contextual Portal — node click opens related environment with continuity cues.
9. Spatial Search Lens — filter result highlights while camera reorients.
10. Knowledge Topology Map — graph local neighborhoods + list/minimap.

## B — Learning and explanatory mechanics
11. Assembly / Disassembly — mechanisms separated into educational parts.
12. Process Conveyor — state flows through ordered verified stages.
13. Dependency Loom — threads reveal actual prerequisites.
14. Layered Storage Cross-Section — cutaway of conceptual architecture.
15. Execution Microscope — step-through rows or objects in code execution.
16. Decision Fork Theater — two pathways split from a grounded tradeoff.
17. Causal Domino Walk — sequence of documented downstream effects.
18. Time-Travel Archive — navigate valid temporal versions with explicit dates.
19. Interactive System Blueprint — layered architecture with hotspots.
20. Proof-by-Transformation — morph equivalent intermediate representations.

## C — Data, statistics and analytical storytelling
21. Distribution Terrain — qualitative framing only; 2D axes always available.
22. Sliceable Metric Object — 3D object with cross-section and accessible table.
23. Time Ribbon Observatory — inspect trends via scrub and aligned 2D graph.
24. Scenario Chamber — compare user-selected parameter settings, not fake values.
25. Data Provenance Thread — follow measure calculation/lineage.
26. Coordinated Viewport Ensemble — 2D exact charts plus 3D contextual stage.
27. Variance Spotlight — direct comparable scales before visual drama.
28. Density Observatory — 3D spatial distribution only when coordinates genuinely spatial.
29. Filter Morph Studio — selections continuously update grounded charts.
30. Outlier Telescope — stage a specific extreme while keeping underlying distribution visible.

## Composition recipe generator
Pick (1) one content topology; (2) one primary pattern; (3) one staging choice (split/central/off-axis/museum/immersive); (4) one material family; (5) one signature state transition; (6) one contrasting secondary surface (DOM prose or exact chart); (7) a tailored mobile form. Then test whether neighboring pages accidentally use the same recipe.
