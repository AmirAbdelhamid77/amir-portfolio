# 08 — Hansa-wide usage coverage and actionable briefs

Do not restrict use to Atlas. All use cases below are hypotheses requiring actual source audit. Prefer user-facing impact and evidence over forcing a showpiece everywhere.

## Knowledge Atlas
- Living graph: 3D/orbit/organic neighborhoods with typed edges; 2D searchable index fallback.
- Evidence trails: expand how an official source supports an approved concept.
- Topic lens: filter Fabric, SQL, statistics while keeping cross-topic links honest.
- Prerequisite explorer: show true directed preconditions; separately explain generic related links.
- Concept comparison chamber: shortlisted topics occupy side-by-side synchronized stages.
- Knowledge provenance: camera follows source-to-concept-to-lesson/question mapping, with review status.

## DP-600 Academy
- OneLake ecosystem cutaway; connections to Warehouse/Lakehouse with source-true semantics.
- Shortcut vs Mirroring contrast using labeled flow paths and text comparison.
- Delta layout/time-travel: animated log/version snapshots tied to explicit correct sequence.
- Optimize/Vacuum visual mechanism; must preserve actual file/version semantics.
- Capacity hierarchy explorer: Tenant > Capacity > Workspace > Item modeled as actual hierarchy.
- Warehouse vs Lakehouse paired galleries showing workload differences; no invented performance claims.
- Graph-to-question challenge: question relations interactive without changing approved answer keys.
- Code trace: DAX, SQL, PySpark, KQL stages, code and trace remain accessible as text.
- Skills outline museum: actual official objectives and coverage statuses, no fabricated totals.

## PL-300 / Power BI
- Query transformations as layered data-shaping flow with before/after tables.
- Filter context and CALCULATE: interactive filter spotlight showing which rows survive.
- Relationships and propagation: traced selected fact/dimension paths with real table names.
- Visual interactions: filter/highlight/none states replay with valid outcomes.
- Measures vs columns: calculation timing explainer.
- Accessible visual lab: compare chart choices with identical fixed source dataset.
- DAX execution: step-by-step state timeline rather than decorative equations.

## SQL / PostgreSQL
- JOIN: animated matching sets grounded in sample rows (accessible matched-row table).
- Window functions: moving frame highlighting ROWS vs RANGE and running totals.
- GROUP BY/ROLLUP/CUBE: expandable group hierarchy with exact aggregates.
- CTE: pipeline vs nested expression conceptual diagram, avoiding false execution promises.
- String/date functions: trace transformations on explicitly provided examples.
- SQL query plan: actual EXPLAIN output only, clearly distinguished from conceptual diagrams.

## Statistics / Data Storytelling
- Sampling: selected sample clearly separated from population; visual randomization not insinuated as fact.
- Distribution explorer: synchronized 2D chart and optional 3D density **only for meaningful axes**.
- Confidence interval: transparent range with text explanation and valid formula.
- Regression diagnostics: emphasize data truth and axis integrity.
- Reproducibility gallery: demonstrate provenance, transformations, versions.
- Narrative evidence walk: annotated chart/story sequence with source links.

## Portfolio / landing
- Hero as a layered cinematic knowledge stage, connected to actual recent content.
- Insight-of-day as an interactive object with relation reveal and date/provenance.
- Card Dealer as spatial sorting/reveal device, not cards simply floating.
- Project dioramas reveal problem → data → solution → validated results with source-backed outcomes.
- Skills gallery: capability maps/objects, with evidence links and accessible categorized list.
- Timeline: chronological camera track with sources; transitions skippable.
- Search discovery: semantic facets become geometric highlights while results remain indexable.

## Business analytics / operations / other references
- Logistics route network: actual locations/flows only; avoid conflating schematic routes with geographic routes.
- Scenario sensitivity field: parameters/units explicit, simulation labeled.
- Pipeline freshness monitor: real timestamps and reliability states, no animated fake streams.
- HSE/legacy content: not homepage flagship unless explicitly reprioritized; optional restrained case-study treatment.

## Prioritization
High: Atlas living graph, DP-600 mechanics, landing knowledge reveal, SQL row trace, evidence-based data stories. Medium: portfolio case-study dioramas and advanced navigation. Low: converting utility tables/forms to GPU scenes. Complexity is earned by meaning.
