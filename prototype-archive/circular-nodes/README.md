# Archived: circular-node graph prototype (rejected)

This folder holds the first prototype, kept only as a record. It is **not** part of
the build and is not referenced by any route.

- Why archived: the owner rejected the layout. It placed nodes on a circle, so the
  positions encoded nothing about the corpus, and the graph content was limited to
  a hand-curated subset rather than derived from the registries.
- Replaced by: `components/knowledge-graph/`, `lib/knowledge-graph/`,
  `app/prototype/network/page.tsx`, with the report in
  `docs/prototype-graph/REPORT.md`.
- Contents: old route (`app/prototype/graph/`), old component and CSS, old data and
  layout helpers, old QA script, and the old report/README/QA screenshots.

Do not restore these files into `app/`, `components/`, `lib/` or `scripts/`; the
successor system covers the same route intent with source-derived data.
