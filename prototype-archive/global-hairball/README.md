# Global hairball prototype — archived 2026-11-07

This folder preserves the first `/prototype/network/` implementation before it was
replaced by the expanding radial tree.

- `graph.tsx` — the client force graph. Its default mode was `global`, which drew
  every visible node and every enabled layer at once.
- `graph.css` — its stylesheet.
- `qa-network-graph.mjs` — the browser QA script for that implementation.

Why archived: the default global view did not teach containment, had no hierarchy,
and produced a label hairball. The replacement is
`components/knowledge-graph/tree-explorer.tsx` with a source-derived tree.

These files are not imported by the active route. They are kept for rollback and
comparison only. `public/graph/dataset.json` is still generated by
`npm run graph:build`; the tree route does not fetch it.
