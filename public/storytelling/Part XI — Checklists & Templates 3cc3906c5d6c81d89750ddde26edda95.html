Part XI — Checklists & Templates

11.1 Executive Story Template

  • Opening: "We expected X, but Y happened."
  • Key Finding: "The main driver is Z."
  • Evidence: "We see this in A, B, and C."
  • Impact: "If nothing changes, we expect D."
  • Recommendation: "We recommend E because it addresses the main driver."
  • Next Step: "The immediate next step is F."

11.2 Data Story Checklist

Audience

  • Identified persona.
  • Assessed technical proficiency.
  • Identified decision authority.
  • Understood what they care about.

Story

  • Defined Big Idea.
  • Can tell the story in three minutes.
  • Narrative has a logical sequence.
  • Only key evidence is included.

Data

  • Data quality is acceptable.
  • Findings are reliable.
  • Limitations are known.
  • Insights are actionable where appropriate.

Metrics

  • Metric matches the question.
  • Absolute vs relative change chosen intentionally.
  • Ratios are meaningful.
  • Mean vs median considered.
  • Statistical significance is not confused with practical significance.

Visuals

  • Every chart has a purpose.
  • Chart matches audience expertise.
  • Headline focuses attention.
  • Context is sufficient.
  • No misleading scales or encodings.
  • Noise is minimized without hiding important variation.
  • Insight is explicitly explained.

Format

  • Chosen based on audience and purpose.
  • Time constraints considered.
  • Channel considered.
  • Audience size considered.
  • Need for permanent record considered.
  • Technical appendix provided when useful.

11.3 Practical Checklists

Before an Analysis Story

  • What decision are we supporting?
  • Who owns the decision?
  • What is the central question?
  • What would change the decision?
  • What evidence is sufficient?

Before a Report

  • Purpose stated?
  • Context explained?
  • Analysis questions explicit?
  • Data and methods reproducible?
  • Findings separated from raw observations?
  • Recommendations tied to evidence?
  • Sources cited?
  • Technical depth matched to audience?

Before a Presentation

  • Purpose defined?
  • Audience persona defined?
  • One central message?
  • Opening hook?
  • Clear structure?
  • One message per slide?
  • Charts highlighted?
  • Text short and readable?
  • Time tested?
  • Transitions practiced?
  • Likely questions prepared?

During Delivery

  • Talk to, not at, the audience.
  • Maintain natural eye contact.
  • Use natural gestures.
  • Vary voice pace/intonation when useful.
  • Pause after key insights.
  • Avoid filler words where possible.
  • Never exceed allocated time.
  • Invite questions.

11.4 One-Page Memory Sheet

Data Storytelling: Data + Narrative + Visuals → Understanding → Decision → Action

Audience: Who are they? What do they know? What decision do they own? What do they need?

Story: Problem → Evidence → Driver → Insight → Impact → Recommendation → Action

Report: Purpose → Context → Questions → Data → Method → Analysis → Results → Conclusion → Recommendations

Presentation: Purpose → Audience → One Message → Structure → Simple Slides → Practice → Delivery → Q&A

Writing: Precise + Concise + Concrete + Clear

Reproducibility: Document → Version → Preserve Raw Data → Script Transformations → Control Randomness → Trace Results

Golden Rules

Visualize the message, not merely the data.
One message per slide.
Minimum sufficient evidence, not maximum available information.
Know the story, don't memorize the words.
Talk to the audience, not at them.
A finding is valuable when it helps answer a decision-relevant question.
