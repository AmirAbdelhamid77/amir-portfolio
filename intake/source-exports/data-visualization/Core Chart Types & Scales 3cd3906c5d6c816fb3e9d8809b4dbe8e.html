Core Chart Types & Scales

Purpose: The core chart-type library — the six workhorse plots plus the scale and trend-line concepts that support them.

4. Histogram

What it is

A histogram visualizes the distribution of one continuous variable by grouping numeric values into intervals called bins and counting observations in each bin.

Example question:

At what ages did monarchs ascend to the throne, and which age ranges were most common?

Anatomy

  • X-axis: continuous variable divided into bins.
  • Y-axis: usually count; depending on the implementation it can also represent density or another normalized quantity.
  • Each bar corresponds to an interval.

Bin width is a critical design choice

A bin width that is too small can produce a noisy, jagged histogram. A bin width that is too large can hide important structure.

Therefore:

There is rarely a universally perfect bin width. Inspect several sensible choices and choose one that reveals the relevant structure without inventing noise.

How to interpret a histogram

1. Modality

Count the prominent peaks.

  • Unimodal: one main peak.
  • Bimodal: two main peaks.
  • Multimodal: several peaks.

Multiple modes can suggest heterogeneous subpopulations or a mixture of processes.

2. Skewness

Skewness describes asymmetry.

  • Right-skewed: longer/extreme tail toward larger values.
  • Left-skewed: longer/extreme tail toward smaller values.
  • Approximately symmetric: tails are reasonably balanced.

A reliable memory aid: the tail points in the direction of the skew.

3. Kurtosis

Kurtosis is a more advanced description related to tail/extreme-value behavior and concentration relative to a reference distribution. The terminology used in the lesson is:

  • Mesokurtic: roughly normal-like reference shape.
  • Leptokurtic: relatively heavier tails / more extreme observations and often a sharper central peak.
  • Platykurtic: relatively lighter tails / fewer extreme observations and often a flatter, broader center.

Important caution: kurtosis should not be reduced to "peak height." Its interpretation is fundamentally about tail behavior and moments; different distributions can have similar-looking peaks but different tail properties.

Common histogram mistakes

  • Treating categorical values as histogram bins.
  • Choosing bins only because they look visually attractive.
  • Overinterpreting tiny fluctuations caused by binning.
  • Comparing histograms with incompatible scales or bin definitions.

5. Box Plot

Why box plots exist

Multiple histograms can become difficult to compare when many categories are involved. Overlapping histograms can become a visual mess; separate panels consume space and make cross-panel comparison harder.

A box plot compresses each group's distribution into a compact statistical summary.

When to use it

Use a box plot when you have:

A continuous variable split by a categorical variable, and you want to compare distributions across groups.

Anatomy

  • Median: line inside the box; 50% of observations are below and 50% above it.
  • Lower quartile (Q1): 25th percentile.
  • Upper quartile (Q3): 75th percentile.
  • IQR:
  • Box: from Q1 to Q3, containing the middle 50% of observations.
  • Whiskers: conventionally extend to the most extreme observations within 1.5 × IQR of the quartile boundaries (implementation details can vary).
  • Points beyond whiskers: commonly displayed as potential outliers/far observations under the chosen rule.

What a box plot lets you compare

  • Typical value via median.
  • Middle-50% spread via IQR.
  • Overall spread via whiskers.
  • Potential outliers.
  • Differences in distribution shape/location between groups.

Important limitation

A box plot is compact, but it hides information. Two groups can have similar box plots while having very different multimodal distributions. For small samples, raw points or a combination of box plot + points can provide useful additional context.

6. Scatter Plot

When to use it

Use a scatter plot for two continuous variables when the goal is to understand their relationship.

Example:

Does house price increase as floor area increases?

Typical mapping:

  • X-axis: explanatory/predictor variable.
  • Y-axis: response/outcome variable.
  • Each point = one observation.

What to inspect

  1. Direction: positive, negative, or no clear direction.
  1. Strength: how tightly points follow a pattern.
  1. Form: linear, curved, clustered, etc.
  1. Outliers: observations far from the general pattern.
  1. Clusters: possible subgroups or latent populations.
  1. Changing variance: whether the vertical spread changes with X.

Correlation

Correlation is useful for quantifying the strength and direction of a linear association.

  • Positive correlation: larger X tends to accompany larger Y.
  • Negative correlation: larger X tends to accompany smaller Y.
  • Near-zero correlation: little linear association.

A key warning:

Correlation is not a complete description of arbitrary relationships.

The Datasaurus examples demonstrate that datasets can share similar correlation while having radically different shapes. A curved, circular, clustered, or otherwise nonlinear relationship may have weak/zero linear correlation despite a strong non-linear relationship.

Trend lines

A fitted straight line can help diagnose whether a linear model is a reasonable approximation.

A smooth/curved trend line can reveal systematic non-linearity when a straight line is inadequate.

Logarithmic axes

When variables span several orders of magnitude, log scales can spread observations more evenly and make multiplicative relationships easier to inspect.

A relationship that is approximately linear on a log-transformed scale can indicate multiplicative/exponential behavior in the original scale, depending on which variable(s) are transformed.

7. Line Plot

Core definition

A line plot is closely related to a scatter plot, but it adds a crucial semantic condition:

Consecutive observations must be conceptually connected.

Time is the most common example because dates have a natural order and neighboring observations describe the evolution of the same process.

Typical use cases

  • Revenue by month.
  • Enrollment by term.
  • Daily active users.
  • Temperature over time.
  • Cases over time.
  • Stock/market measures over time.

Multiple lines

Multiple series can be shown together to compare trajectories, such as sales for several regions over time.

Linear vs exponential growth

If a quantity grows by approximately a constant absolute amount per time step, its original-scale trajectory can be approximately linear.

If it grows by approximately a constant percentage/multiplicative factor, the original-scale trajectory can be exponential.

A log transformation of the Y-axis can turn an exponential relationship into an approximately straight line, making exponential growth easier to diagnose.

Critical warning: time on X does not automatically imply a line plot

Suppose every point represents a different song released on a different date and the score is a critic rating. The observations are not successive measurements of the same evolving quantity. Connecting songs with a line would imply continuity that does not exist.

Use a scatter plot when the observations are not conceptually connected—even if the X-axis is a date.

8. Bar Plot

When to use it

A bar plot compares a metric across categories. Common metrics include:

  • Count
  • Percentage
  • Sum
  • Mean
  • Other meaningful category-level measures

Why zero matters

Bars encode magnitude through their length/height from a baseline. Therefore, a zero baseline is conceptually important for honest magnitude comparisons. Truncating a bar chart can exaggerate differences.

Horizontal vs vertical

Horizontal bars are often preferable when category labels are long, because they remain readable without rotating text.

Sorting

Sort categories by the metric when ranking is important. This makes highest, lowest, and ties much easier to detect.

Stacked bar charts

Stacked bars are useful when categories form components of a total and the total has meaning. A classic case is percentages summing to 100%:

This allows comparison of both total composition and how composition changes across groups/time.

Use caution when comparing segments that do not share a common baseline: stacked segments away from the baseline are harder to compare precisely.

Bar plot vs box plot

  • Bar plot: usually one summarized metric per category.
  • Box plot: distribution of many observations within each category.

For example:

Average salary by department → Bar plot.
Distribution of salaries within each department → Box plot.

Bar plot vs histogram

This distinction is essential:

  • Histogram: continuous variable → bins/intervals → distribution.
  • Bar plot: categories → metric → comparison.

Histogram bins represent adjacent numeric intervals; bar categories are discrete groups.

9. Dot Plot

What it is

A dot plot can serve essentially the same category-versus-metric role as a bar plot, but it represents the value with a point positioned on a numeric axis rather than a bar extending from zero.

Advantage 1: logarithmic scales

Bar charts depend on a zero baseline. A logarithmic axis cannot represent zero because:

A dot plot does not require the value to be represented as a bar extending from zero, so a logarithmic numeric axis can be used.

This is particularly valuable for quantities spanning several orders of magnitude, such as astronomical masses or other multiplicative measurements.

Advantage 2: multiple metrics

Dot-based displays can place multiple metric values for the same category on the same numeric framework, which can be more space-efficient and flexible than multiple bars.

Linear vs logarithmic interpretation

  • Linear scale: visual distance corresponds to additive differences.
  • Log scale: equal visual distances correspond to equal multiplicative ratios.

For example, on a base-10 log scale, equal steps represent ×10 changes.

Dot plot vs scatter plot

Both use points, but their analytical structures differ:

  • Dot plot: category + numeric metric; compare category-level values.
  • Scatter plot: numeric + numeric; inspect relationships between observations.

10. Logarithmic Scales — Deeper Reference

A log axis is useful when:

  • Values span multiple orders of magnitude.
  • Ratios are more meaningful than absolute differences.
  • Exponential growth needs to be visualized.
  • Multiplicative structure is important.
