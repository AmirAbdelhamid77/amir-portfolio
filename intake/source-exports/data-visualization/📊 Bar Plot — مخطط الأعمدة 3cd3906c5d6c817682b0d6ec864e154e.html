📊 Bar Plot — مخطط الأعمدة

متى تستخدمه؟

لمقارنة مقياس بين فئات. مثل:

  • العدد.
  • النسبة.
  • المجموع.
  • المتوسط.
  • أي مقياس آخر له معنى على مستوى الفئة.

لماذا الصفر مهم؟

الأعمدة تمثل الحجم من خلال طولها أو ارتفاعها انطلاقًا من خط أساس. لذلك فإن الصفر مهم للمقارنة الصادقة. قطع المحور يمكن أن يضخم الفروق.

أفقي أم رأسي؟

الأعمدة الأفقية أفضل غالبًا عندما تكون أسماء الفئات طويلة لأنها تظل مقروءة دون تدوير النص.

الترتيب Sorting

رتّب الفئات حسب المقياس عندما يكون الهدف هو Ranking. فهذا يسهل اكتشاف الأعلى والأدنى والتعادلات.

Stacked Bar Chart

مفيد عندما تمثل الفئات مكونات من إجمالي له معنى. مثال كلاسيكي: نسب مجموعها 100%:

يسمح ذلك بمقارنة إجمالي التركيب وكيف يتغير التركيب بين المجموعات أو عبر الزمن.

لكن المقارنة بين أجزاء لا تشترك في نفس خط الأساس تكون أقل دقة.

Bar Plot مقابل Box Plot

  • Bar Plot: قيمة ملخصة واحدة عادة لكل فئة.
  • Box Plot: توزيع عدد كبير من المشاهدات داخل كل فئة.

مثال:

متوسط الراتب حسب الإدارة → Bar Plot.
توزيع الرواتب داخل كل إدارة → Box Plot.

Bar Plot مقابل Histogram

هذه نقطة أساسية جدًا:

  • Histogram: متغير مستمر → فترات رقمية → توزيع.
  • Bar Plot: فئات منفصلة → مقياس → مقارنة.

Bins في Histogram تمثل فترات رقمية متجاورة، بينما فئات Bar Plot مجموعات منفصلة.
