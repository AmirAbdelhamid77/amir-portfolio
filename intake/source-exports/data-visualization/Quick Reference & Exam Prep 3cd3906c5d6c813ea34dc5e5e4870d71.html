Quick Reference & Exam Prep

Purpose: Fast-recall material — the pre-publish checklist, comparison tables, common exam/interview traps, and the mental model diagram.

20. Practical Interpretation Checklist

Before publishing a visualization, ask:

  • What exact question does this chart answer?
  • Are the variable types appropriate for the chosen plot?
  • Is the axis scale appropriate and clearly labeled?
  • Is zero meaningful and handled correctly for bars?
  • Are categories ordered in a useful way?
  • Are bins sensible and tested for histograms?
  • Does a line imply a connection that really exists?
  • Could a log scale reveal multiplicative structure?
  • Are outliers real observations, data-quality issues, or both?
  • Does aggregation hide important distributional information?
  • Is the chart readable without unnecessary decoration?
  • Could a different plot communicate the same insight more accurately?

21. High-Value Comparison Table

QuestionRecommended plotWhy
What is the distribution of one numeric variable?HistogramShows distribution shape and frequency across numeric intervals.
How does a distribution differ by group?Box plotCompact comparison of median, quartiles, spread, and unusual observations.
Are two numeric variables related?Scatter plotShows point-level relationship and form.
How does a connected quantity evolve?Line plotEmphasizes sequential change and trajectories.
Which category has the largest/smallest metric?Bar plotDirect magnitude comparison from a zero baseline.
Which category has a value on a very wide multiplicative scale?Dot plotCan use a log axis without requiring a zero bar baseline.

22. Exam / Interview Traps

Trap 1 — "X-axis is Date, therefore Line Chart"

False. A line requires conceptually connected consecutive observations. If each date corresponds to an independent item, such as a different song, a scatter plot may be better.

Trap 2 — "Bar chart and histogram are the same"

False. Histograms show a continuous distribution using numeric intervals; bar charts compare discrete categories using a metric.

Trap 3 — "Correlation describes every relationship"

False. Correlation primarily describes linear association. Nonlinear structures can have weak correlation.

Trap 4 — "Box plot shows the mean"

Not by default. The central line is the median. A mean may be added separately depending on the implementation.

Trap 5 — "More bins always means more information"

False. Excessively narrow bins can turn random variation into visual noise.

Trap 6 — "Bar charts can freely use a log axis"

Not when the bars must originate at zero. A dot plot is a common alternative when a logarithmic category-level metric axis is required.

Core principle: The best chart is not the one that contains the most information. It is the one that makes the information relevant to the question easiest to see without introducing misleading visual implications.

25. Advanced Decision Framework

Use this question-first framework:

Analytical questionRecommended visualization
What is the distribution of one continuous variable?Histogram
How do several distributions differ?Box plot
What is the relationship between two numeric variables?Scatter plot
How does a connected measure change over time/sequence?Line plot
How does a metric compare across categories?Bar plot
Need category comparison with a log scale or multiple metrics?Dot plot
Need a third variable in a scatter plot?Color or facets; size/alpha with caution
Need distributions + pairwise relationships for a small set of variables?Pair plot
Need compact correlations across many continuous variables?Correlation heatmap
Need profiles/patterns across many continuous variables?Parallel coordinates
Is the underlying phenomenon naturally cyclical?Polar/rose plot
Need a pie chart for ordinary category comparison?Prefer bar chart
Tempted to use dual Y-axes?Prefer separate panels
