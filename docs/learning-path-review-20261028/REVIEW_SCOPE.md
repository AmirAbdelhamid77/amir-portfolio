# Source-grounded learning-path review

Scope: concept classification, preparation and prerequisites, source-to-question/application associations, progression and learner navigation. This is not renewed approval of every original answer, product execution, or human SME publication approval. No Atlas candidate relation is promoted. No Cloudflare publication is authorized.

## Evidence and decisions

The local source corpus is unchanged. Statistics uses all 43 existing section objectives and source section anchors, existing lab `sections` mappings, the ten analyst statistics prompts, and the source's own interpretations/caveats. Visualization uses all 27 original lesson entries/takeaways, twelve scenarios and existing local application routes. Fabric's 720 source notes retain their exact `questionIds`, points and caveats; 923 explicit question associations across notes/the authored ingestion lesson are checked by identity. The authored ingestion lesson retains its stated prerequisite skills and three transfer cases. Twenty intake lessons and their declared assessment/prerequisite associations remain in a separate review-only path.

Each of the 35 topic entries now declares preparation skills, a stage, a reason, prerequisite-topic keys and resolvable evidence. These prerequisite choices are **reviewed pedagogical inferences**, not quotations of a source-mandated course sequence, mastery gates, or published semantic graph edges. Source-declared lesson requirements and association IDs are identified separately.

Important corrections: test-statistic formula/glossary belong to hypothesis testing, a skew/center question to description, and an observation's z-score question to distributions. Sampling distribution (§12) appears before CLT (§11) in the guided sequence despite the source's original numbering. Source pages and numbering are preserved. Reference sheets are not locked behind advanced synthesis. Python's entry reading expects programming knowledge; no zero-to-programming local course is claimed. RTI introductory preparation does not require completing every DAX, SQL or deployment topic.

## Association strength and gaps

1. **Source-explicit:** original IDs/section associations, checked for existence and correct canonical destinations. This does not validate an answer key.
2. **Reviewed concept match:** lesson objective/takeaway compared with the actual scenario or question prompt. No claim of complete assessment coverage.
3. **Topic context:** practice from an existing topic beside external reading; explicitly not a verified article-specific assessment.
4. **Unscored source-based explanation task:** used for gaps and reflection. It is not a graded bank item or live execution result.

Every step has an explanation task and source points, but only actual existing applications are labeled local labs. Missing bank matches and missing executable labs are reported in REVIEW_AUDIT.json rather than filled with unrelated questions or invented product execution. All unassigned question IDs remain in the normal topic library; there is no forced mapping to a lesson.

## Representation and state

Considered an unqualified prerequisite graph, a very long resource list, and a guided editorial rail. Selected the rail with bounded rendering, stage/search filters, source → practice → application → explanation, anchor restoration and previous/next steps. It expresses sequence without falsely publishing scientific edges. No new library or backend is required. The 20 unapproved intake lessons have their own noindex path and source-declared relationships; they never enter the ordinary paths.

No new mastery is inferred from opening a lesson. Existing question IDs, scoring, saved best scores, session namespaces, source bodies, formulas, review states and publication gates are retained. Path filter state is local UI state; it does not migrate learner data. The preflight baseline and rollback copies are in BASELINE.json and before/. MANIFEST.json is an additive successor, leaving earlier task manifests immutable. Restore only matching owned files for rollback; preserve unrelated and later edits.
