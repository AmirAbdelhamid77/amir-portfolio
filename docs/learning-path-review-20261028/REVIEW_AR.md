# Hansa — مراجعة التصنيف ومسارات التعلم

نسخة منفذة محليًا بتاريخ 2026-10-28، بلا نشر على Cloudflare. نقطة البداية: [مكتبة التعلم](http://127.0.0.1:4318/study/). كل مجال له مسار يبدأ بالأساسيات ثم التطبيق والتقدم، مع بقاء صفحات المحتوى الأصلية وأسئلتها وتقدّم المتعلم.

## ما اكتمل

- مراجعة **35 موضوعًا في 8 مجالات**: مستوى البداية، المهارة المتوقعة، التحضير المفاهيمي، سبب الترتيب والمراجع. المتطلبات المقترحة استنتاجات تربوية موثقة؛ لا تُقدَّم كحواف Atlas منشورة أو شروط إكمال إلزامية.
- **163 تغييرًا في التصنيف** موثقة بمعرّف السجل والتصنيف السابق والحالي والسبب. مثال: سياق إخفاء البيانات أو Git لا يتحول إلى «أساسيات OneLake» لمجرد ورود كلمة تخزين. إحصاء الاختبار ضمن اختبار الفرضيات، والسؤال عن المتوسط في توزيع ملتوي ضمن الوصف، وتوحيد الملاحظة إلى z ضمن التوزيعات.
- **799 خطوة**: 71 درسًا محليًا موجودًا، و720 ملاحظة دراسة مصدرية، و8 قراءات تأسيسية خارجية. الملاحظات والقراءات ليست 799 درسًا مؤلفًا جديدًا أو منهجًا مكتملًا.
- ربط كل خطوة بمصدرها، والممارسة المطابقة المتاحة، والتطبيق الموجود أو مهمة شرح واضحة. توجد **1,074 رابطة إلى أسئلة** تغطي **956 سؤالًا فريدًا**: 923 رابطة أصلية صريحة، و45 مطابقة مفاهيمية مراجعة، و106 ممارسات في نفس موضوع القراءة الخارجية. الرقم الأول يحسب الروابط لا الأسئلة الفريدة.
- **55 رابطة لتطبيقات موجودة** و799 مهمة شرح غير مُقيَّمة مبنية على نقاط المصدر. لا تنفيذ Fabric أو SQL أو Python حقيقي مُختلق.
- ترتيب توزيع المعاينة قبل نظرية النهاية المركزية، مع الاحتفاظ بأرقام وعناوين المصدر. القوائم المرجعية لا تُقفل وراء مرحلة متقدمة. رابط «العودة إلى هذه الخطوة» يرجع من الدرس أو السؤال أو التطبيق إلى نفس الخطوة؛ السابق/التالي يلتزمان بالترتيب الجديد.
- 20 درسًا من المحتوى غير المعتمد و28 رابطة سؤال معلنة في مصدرها داخل مسار مراجعة منفصل، غير مفهرس، دون تغيير حالات المراجعة أو إتاحة التقييم.

## حدود التغطية العلمية

**40 خطوة بلا سؤال بنك يمكن الدفاع عن مطابقته المباشرة، و748 خطوة بلا تطبيق تنفيذي محلي.** يظهر هذا النقص داخل الواجهة، وتُستخدم مهمة شرح غير مُقيَّمة بدل ادعاء وجود اختبار أو معمل. توجد 485 هوية سؤال لم تُفرض على درس بعينه؛ تبقى متاحة في مكتبة موضوعها. هذه فجوات تغطية محفوظة في REVIEW_AUDIT.json، لا أسئلة محذوفة.

المراجعة تخص التصنيف، والمتطلبات المفاهيمية، والربط التعليمي. لم تُعَد مراجعة كل إجابة أو نتيجة حسابية في جميع البنوك، ولم تُمنح موافقة بشرية جديدة للنشر العلمي. صلاحية الروابط ووجود الهوية لا يثبتان صحة مفتاح الإجابة. النصوص والمغالطات وتصحيحاتها والتحفظات الأصلية محفوظة، مع تسمية التصحيح بوضوح. قوائم العلاقات المقترحة لا تتحول تلقائيًا إلى معرفة Atlas معتمدة.

## الأداء والقيود المتبقية

تُعرض أول 12 خطوة أو خطوة الرابط المحددة، بدل آلاف عناصر الصفحة. هذا تحسين لعدد العناصر ولا يثبت سرعة تحميل ميدانية. ملف HTML لمسار Fabric يحوي بيانات الخطوات كاملة ويبلغ **1,065,223 بايت قبل الضغط**؛ لم تُقسّم حمولته إلى صفحات بيانات بعد. لا ادعاء LCP/INP جديد لهذه المسارات. المقروئية والمطابقة التعليمية تسبقان إضافة رسوم أو علاقات شكلية غير معتمدة.

## ملفات المراجعة

- TOPIC_REVIEW_MATRIX.md: الموضوع والمتطلبات وسببها ومراجعها، ثم الوحدات المرتبطة به وفجواتها.
- REVIEW_SCOPE.md: منهج الاستدلال وروابط NIST وMicrosoft وPython والمصادر المحلية وحدودها.
- UNITS.json / REVIEW_ONLY_UNITS.json: المصدر والهدف والأسئلة والتطبيقات وقوة الربط لكل خطوة.
- CLASSIFICATION_CHANGES.json: دفتر تغيّر التصنيف، لا تغيير نص المحتوى.
- BASELINE.json / MANIFEST.json / before/: بصمات البداية وملكية التعديل ونسخ الرجوع. LEARNING_PATH_ONLY.patch يعرض التغيير مقارنة بالحالة المحفوظة، بما فيها التعديلات السابقة للمستخدم.
- evidence/: لقطات فعلية، نتائج المتصفح، وتسجيلان لفتح السؤال والرجوع ثم فتح ملاحظة Fabric والرجوع.

## التشغيل والرجوع

الخادم المحلي الحالي على 4318؛ ملف التصدير في الحزمة تحت out/ يمكن خدمته بخادم ملفات ثابت يدعم مجلدات index.html. لا ترفع هذه الحزمة إلى Cloudflare. ملفات source-overlay/ هي تغييرات هذه المهمة فقط فوق checkout الحالي؛ ليست مستودعًا مستقلًا كامل التبعيات.

للرجوع: راجع MANIFEST.json، وتأكد أن بصمة الملف الحالي لا تزال مطابقة لبصمة هذه النسخة، ثم أعد فقط الملفات المملوكة الموجودة سابقًا من rollbackPath. الملفات الجديدة التي beforeSha256 لها فارغة تُزال فقط بعد التأكد من عدم وجود تعديل لاحق عليها. لا reset أو stash أو إرجاع جماعي للمستودع. لا تُعِد ختم سجلات الإصدارات السابقة.

للمراجعة البصرية والعلمية النهائية: افتح مسار الإحصاء من §12 ثم §11، و§15 ثم أسئلته وتطبيقه والرجوع لنفس الخطوة؛ افتح ملاحظة Fabric وروابطها؛ وافحص مهارة الدخول وتحضير الموضوع لكل مجال. وافق على البنية التعليمية بعد قراءة الأسباب والفجوات، بشكل مستقل عن النشر.
