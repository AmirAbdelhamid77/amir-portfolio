# Answer-key errata — `patrick-dp600` pack (2026-11-17)

Owner request (2026-11-17): resolve the `patrick-dp600` answer-key defects that the question-insight
build reported. This file is the record of what was wrong, why, what changed and how it was checked.

## Cause: an importer bug, not the source

`scripts/convert-community-banks.mjs` read the answer letter from the `<summary>` label of each
question's answer block. Every label in the source is the word **"Answer"**, so the pattern
`[A-D]` matched the capital **A** of "Answer". All 30 questions were keyed **A**.

The real key is stated in the block body as `**Correct: X**`
(`content/intake/hansa-integration/packs/patrick-dp600/source.md`, Patrick Wiloak, CC BY 4.0).
8 questions really are A (007, 008, 011, 015, 019, 022, 025, 028). The other **22 were wrong**.

The bug made the provenance claim "Answer keys preserved verbatim from the source" untrue. The fix
makes it true again: every key now equals the source's own key, and no key was invented.

The Howard pack (`howard-dp600`, 120 questions) goes through the same converter but reads a JSON
`answer` field. It was checked against its source: 0 mismatches.
