- Atlas ما زال في انتظار الاعتماد: صفر عقد وحواف منشورة، وغرفة المراجع تعمل. لم تتغير حالات الأسئلة أو مفاتيح الإجابات أو بوابات الاعتماد.
- لا خدمات أو bindings جديدة. إعداد التوافق بقي كما كان. المستودع وتعديلاته الأخرى لم تُرجع أو تُستبدل.
