## Open caveats

- Source coverage limits: 42 concepts / 49 semantic edges, all `technical_review`, one
  subject (Fabric). The prototype's other four domains have reading rooms but no
  candidate relations, shown honestly as such.
- Browser/AT not exercised: no screen-reader run, no Safari/Firefox, no touch hardware,
  no forced-colors pass beyond CSS. Axe is not an AT test.
- Known prototype defects still present (deliberately): the panel repeats the concept
  name as large display text (now a `<p>`, with the section named by it), and the
  `?concept=` deep link is written with `replaceState`, so a reload keeps the concept
  but the browser back button does not step through neighbourhoods.
- The flag-on export puts candidate data in `out/`; the shipped export must always be
  built with the flag off. This record's final build is flag-off and verified.
- Performance is one local run per surface, not field data.
- Next atomic task: owner visual acceptance of R1; then R2 (Home wiring of the accepted
  neighbourhood) with the same flag discipline.
