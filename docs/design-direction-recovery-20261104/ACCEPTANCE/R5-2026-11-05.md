## Open caveats

- Source coverage: 3 editions, all `technical_review`, 0 published. The scene can
  show at most those three; the ledger's corpus rows are the whole-repository
  semantic ledger, which is a different denominator, and the scene says so.
- The ledger is pinned to the 1 Nov 2026 summary. If the ledger is regenerated,
  `tests/knowledge/closing.test.mjs` fails until `CORPUS_COVERAGE` is updated;
  that is deliberate, but it means R5 cannot silently follow a new ledger.
- The flag-on export contains candidate data in `out/`; the shipped export must
  always be built with all five flags off. This record's final build is flag-off.
- The review close's rules are dead bytes in the public stylesheet (5,599 B of
  248,019 B). Splitting the scene into a separate stylesheet was rejected because
  the stage already ships one stylesheet and a second request costs more than the
  dead rules.
- The public build gained one request (+10,956 B JS) because the closing module
  joins the stage's client graph. The closing scene's own DOM is unchanged; the
  extra node is the script tag that loads that chunk.
- Saved cards live in `localStorage` only. There is no pocket, no cross-device
  sync and no server write; a cleared browser loses them, by design.
- With the review flag on and JavaScript off, the quote, ledger and claims still
  render (server-rendered), but the kept list stays empty.
- Browser/AT not exercised: no screen-reader run, no Safari/Firefox, no touch
  hardware, no forced-colors pass. Axe is not an AT test.
- Performance is a single local run per build, not field data. The public LCP
  moved 660 -> 756 ms between the M6 baseline and this run with CLS 0; the
  five-flag review build measured 1,264-1,332 ms at `/`, which is not comparable
  with R4's 844 ms because R4 measured `/?insight=…#today`.
- `verify-knowledge-atlas.mjs` is blocked by five untracked `EGM.md` documents
  created at 14:12 today (including `app/EGM.md`). They are not part of R5 and
  were left in place for their owner.

  performance) only after acceptance.
