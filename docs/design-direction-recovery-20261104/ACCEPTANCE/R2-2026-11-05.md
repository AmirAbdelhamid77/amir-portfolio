## Open caveats

- Source coverage: 42 concepts / 49 relations, all `technical_review`, one subject
  (Fabric), 0 published. The edition's own neighbourhood is 4 relations; Direct Lake
  is the 8-relation expand case.
- The flag-on export contains the candidate data in `out/`; the shipped export must
  always be built with both flags off. This record's final build is flag-off.
- Emitted chunks are not a leak by themselves: the flag-off export still writes the
  slice chunks to disk, but the Home never requests them and the Home HTML contains
  no candidate id. A host that serves arbitrary `_next/static` files still exposes
  class names and the R1 surface's compiled data reachable only through the gated
  route (which exports a 404). Treat that as review-build residue, not publication.
- Browser/AT not exercised: no screen-reader run, no Safari/Firefox, no touch
  hardware, no forced-colors pass. Axe is not an AT test.
- Performance is a single local run per build, not field data; the long-task count
  varies between runs (2-3) with the same CLS 0.
- The R1 route's rendering changes in two small places because the field and panel
  are shared (duplicate related tag, expand control visibility). Its route, model and
  interactions are unchanged.
