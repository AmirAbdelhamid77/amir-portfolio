## Open caveats

- Source coverage: 3 editions, all `technical_review`, one public feed, 0
  published. The dealer shows 3 cards per edition.
- The flag-on export contains candidate data in `out/`; the shipped export must
  always be built with all four flags off. This record's final build is flag-off.
- The dealer chunk and CSS are emitted in the flag-off export but never
  requested; that is the same pattern as R2/R3.
- Saved cards live in `localStorage` only. There is no pocket, no cross-device
  sync and no server write; a cleared browser loses them, by design.
- With the review flag on and JavaScript off, the trigger opens nothing (the
  chunk is client-only). The public inline dealer is unchanged.
- Browser/AT not exercised: no screen-reader run, no Safari/Firefox, no touch
  hardware, no forced-colors pass. Axe is not an AT test.
- Performance is a single local run per build, not field data. Flag-off LCP
  varied 756-860 ms across R3/R4 runs with CLS 0; the review build's LCP was
  844 ms with the dealer closed and unchanged after opening it.
- `verify-knowledge-atlas.mjs` is blocked by five untracked `EGM.md` documents
  created at 14:12 today (including `app/EGM.md`), which the runtime inventory
  does not know. They are not part of R4 and were left in place for their owner.
