  activation" survives.
- Prototype reference: `intelligent-atlas/prototype/index.html` (timeline scene) +
  `app.js` (`renderTimelineCards`, `renderCables`, `renderRuler`,

  (Fabric), 0 published. The fan displays 3 editions among 15 days.

  always be built with all three flags off. This record's final build is flag-off.
- Emitted chunks are not a leak by themselves: the flag-off export still writes the
  fan chunk and CSS to disk (like the R2 slice), but the Home never requests them.

  hardware, no forced-colors pass. Axe is not an AT test.

  long-task count moved 2 -> 3 between runs; CLS stayed 0.

  the settle is visually equivalent but not frame-identical.
