## Composition and tokens

Use existing --background/--card/--foreground/--primary/--accent/--warning. Local stage surfaces mix these tokens, leaving global theme/navigation intact. Large typography, structural aperture rings, diagonal cutaway slabs, a single active signal, visible contact shadows and occlusion distinguish background, mechanism, rail and reading plane at rest. No particle storm, equal tile grid, looping intro or glass-card wall.

Desktop 1440/1280: title left, instrument right, lower temporal rail; editorial scenario and separate deck workbench below. Mobile 390/320: compact editorial statement, reduced instrument, touch rail, readable scenario and stacked card with inline reading sheet; no tiny fanned text. 768 stacks safely. Reading glyphs never parallax. Coarse pointer/reduced motion turns off environmental parallax and positional choreography.

## Storyboard / state contract

1. READY: semantic content immediately visible; instrument planes settle once, no loading barrier.
2. MANIPULATE: hero control and scenario radio share ExperimentState for the selected ID. deriveVerdict changes labels/geometry/readout together. No synthetic observed data or live Fabric execution.
3. DATE: drag/swipe/wheel/arrow → same controlled ID → title/model/deck/Atlas update; spring retargets; URL/history kept. Axis is ordered editions, NOT proportional elapsed time.
4. REVEAL: anchored article opens sourced reasoning then caveat/evidence; exact model state remains readable in a table.
5. DEAL: deck → arc → hand with 3D face/back rotation; inspect → readable panel; Escape/close returns focus; collect reverses state. Repeated input cancels previous motion.
6. ATLAS: default public projection only. No eligible edges → explicit review-pending contextual concept and real lesson/practice links. Approved graph interaction is BLOCKED by publication, not simulated.

## Acceptance gates

Depth recognizable in static first frame; timeline is a continuously draggable measured rail with momentum and visible focused depth, not static chips; card flight/flip/return visible in actual captured frames. Model changes real derived output and reset restores it. 320/390/768/1280/1440 light/dark, keyboard, emulated touch, reduced motion, no-JS archive, source links, history and storage checked separately. Automated axe is sampled A/AA coverage, not WCAG certification. Lab LCP/CLS/event durations and frame pacing are local observations, not field INP. Owner visual approval and any real-device/screen-reader gaps remain explicit.

## Representation decision (0–5, policy weights 30/25/15/15/10/5)

Plain text/table: 5/4/2/5/5/5 = 86; rich SVG + accessible DOM: 5/5/5/4/5/4 = 96; WebGL + DOM: 5/4/4/2/4/2 = 77. Selected SVG/DOM preserves exact categorical semantics and gives causal interaction without new dependencies. Scores are design judgments, not measured user-study results.
