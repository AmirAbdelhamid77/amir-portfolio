## Reproduce everything

```bash
# from the repo root, with the source package on disk
npm run import:fabric -- --source "../Amirs_Fabric_Lab_Merged_834_Deployment_Package"
npm run test:fabric
npm run report:fabric
npm run build
npm run test:e2e:fabric
```

Reports 02, 03 and the JSON/CSV artifacts are regenerated by `report:fabric`; the
figures in 01, 04, 05 and 06 are hand-written from observed runs on 2026-10-24.

## The one-paragraph summary

834 questions imported once from 18 packs, classified against the official DP-600
objectives, served through nine static routes with a single scoring engine, persisted
in an isolated versioned namespace, measured in a real browser and deployed to
Cloudflare Workers Static Assets. The bank cannot support an authentic
blueprint-weighted simulation — 2.7% of its focused questions cover the semantic-model
domain against an official 25–30% — and the product says so in the hub, the mock set-up,
the results screen and the coverage report rather than inventing balance.
