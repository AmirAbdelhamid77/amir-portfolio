## 3. Beyond EasyUI: distinct Atlas architecture gate
If working on full Knowledge Atlas, evaluate React Flow/XYFlow (or justified alternate engine) separately. Requirements: semantic typed edges, focus+context, clustering, pan/zoom, node search, graph data model, link provenance, keyboard accessible outline, small screen behavior, performance limits, and no structural-only links masquerading as knowledge. Do not install a graph engine from this pack without explicit architectural evaluation.
